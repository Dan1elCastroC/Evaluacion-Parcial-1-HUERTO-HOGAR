# HuertoHogar - Evaluación Parcial 1

Tienda online de HuertoHogar, desarrollada con HTML, CSS y JavaScript (Bootstrap 5) para el
ramo DSY1104. Corresponde a la primera entrega del proyecto: navegación de la tienda, catálogo
de productos, carrito de compras con localStorage, formularios con validación en JavaScript y
un panel administrativo básico para productos y usuarios.

## Estructura del proyecto

- `index.html`, `productos.html`, `producto-detalle.html`, `carrito.html`: vistas de la tienda.
- `login.html`, `registro.html`, `contacto.html`: formularios con validación.
- `nosotros.html`, `blogs.html`, `blog-detalle-1.html`, `blog-detalle-2.html`: contenido informativo.
- `admin/`: panel administrativo (home, listado y formulario de productos, listado y formulario
  de usuarios).
- `assets/estilo.css`: hoja de estilos externa del sitio.
- `assets/script.js`: catálogo de productos, lógica del carrito y validaciones de formularios.
- `Instructions/`: documentos entregados por el docente para esta evaluación.

## Cómo verlo

Basta con abrir `index.html` en el navegador; no requiere instalación ni servidor, ya que todo
el proyecto es HTML/CSS/JS estático.
